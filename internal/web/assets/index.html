BUILT TO OBSERVE, MADE TO MOVE

你的 DNS，长时间观察。

DNS Monitor 是运行在 Windows 上的便携监测工具。通过定期发送解析请求，帮助你选择稳定、快速、解析可信的 IPv4 DNS。

01

开始监测

添加服务器，填写供应商及访问地址。支持的协议以地址校验结果为准，常用写法如下。

UDP
1.1.1.1
TCP
tcp://1.1.1.1:53
DoT
tls://dns.example.com
DoH
https://dns.example.com/dns-query
DoQ
quic://dns.example.com

加密协议可用域名地址，但建立连接时仅使用 IPv4。不兼容的地址格式会在保存时明确提示。

02

如何判定污染

在服务器管理中勾选你认可的“可信 DNS”。系统将被测答案与可用的可信答案比对；可信参考一致且被测结果不一致时，记为污染。

参考失败、参考之间不一致或缺少参考时，不据此判定污染。地域调度和 CDN 也会返回不同答案，应结合原始记录复核。

打开服务器详情，点击结果中的域名标记，可以标记污染、取消污染，或恢复自动判定。人工判定持续作用于该服务器、域名和记录类型，原始探测证据仍保留。

03

如何读懂指标

可用率
按采样覆盖时长加权的响应比例；收到错误响应也说明服务器可达，离线退避不会被当作成功。
查询成功率
成功完成解析的比例；超时及解析错误计入失败。
平均 / P95 时延
成功查询的平均响应速度，以及 95% 的成功查询所处的时延水平。
覆盖率
体现所选时间区间的采样覆盖程度，监测不足时不急于评级。
04

评级与数据保留

质量评分综合可用率（45%）、查询成功率（35%）及 P95 时延（20%）。A ≥ 95 分，B ≥ 85 分，C ≥ 70 分，D < 70 分；存在污染时优先评为 F。

P95 时延 ≤ 50 ms 时获得全部时延分，≥ 2000 ms 时为零分，中间线性递减。样本或时间覆盖不足显示“待评估”。详情可查看采样数与覆盖率；退避期间未发生的探测不会伪造成成功。

每次实际探测的原始记录保留滚动 30 天，超期自动删除。图表按时间聚合，CSV 导出原始记录。
