DNS Monitor 是运行在 Windows 上的便携监测工具。通过定期发送解析请求，帮助你选择稳定、快速、解析可信的 IPv4 DNS。

01

开始监测

添加服务器，填写供应商及访问地址。新安装默认探测 www.youtube.com；也可导入服务器 CSV，预览后逐项选择跳过或覆盖重复项。支持的协议以地址校验结果为准，常用写法如下。

UDP
1.1.1.1
TCP
tcp://1.1.1.1:53
DoT
tls://dns.example.com
DoH
https://dns.example.com/dns-query
DoQ
quic://dns.example.com

加密协议可用域名地址，但建立连接时仅使用 IPv4。不兼容的地址格式会在保存时明确提示。

02

如何判定解析质量

在服务器管理中勾选你认可的“可信 DNS”。系统按域名和记录类型，合并这些服务器的 IPv4 答案：TTL 未到期的是新鲜参考，超过 TTL 的答案可在配置的历史期限内继续作为参考。仅可信 DNS 可以扩充参考集合。

参考一致
全部返回 IP 都在新鲜参考中。
正常
全部 IP 都曾出现在有效参考中，但至少一个只命中近期历史；人工取消异常也显示正常。
可疑 · E
存在参考未见的 IP，但这些 IP 的前两段均匹配同域名的有效参考。
疑似污染 · F
至少一个 IP 既不在有效参考中，前两段也不匹配。此项是规则判断，不代表已证实污染。

前两段相同即 /16 匹配，例如 57.144.152.1 与 57.144.186.1。多个 IP 逐个比较，整次回答取最差档；没有有效参考、查询失败或无 IPv4 答案时显示待判定。直接使用现有有效的新鲜与历史集合，不等待所有可信 DNS 返回；某个来源离线或参考过期，不阻止使用其余有效参考。可信 DNS 的周期探测持续补充集合，仅在集合为空时尝试补采。

可信只豁免污染判定，不代表服务可用。可信 DNS 自身固定显示“用户可信 / 无污染”，不会评 E/F。点击结果中的域名标记，可以确认污染、标记正常，或恢复自动判定。人工判定持续作用于该服务器、域名和记录类型，原始证据仍保留。旧版自动污染记录仅作为证据保留，不参与当前 E/F 评级。

03

如何读懂指标

可用率
按采样覆盖时长加权的响应比例；收到错误响应也说明服务器可达，离线退避不会被当作成功。
查询成功率
成功完成解析的比例；超时及解析错误计入失败。
平均 / P95 时延
成功查询的平均响应速度，以及 95% 的成功查询所处的时延水平。
覆盖率
体现所选时间区间的采样覆盖程度，监测不足时不急于评级。
04

评级与数据保留

总览的当前解析质量取近期窗口内的最新正式轮次；窗口内无采样或最新结果待判定时，不沿用旧的正常状态。最新一轮正式探测全部查询失败时，当前评级立即显示“不可用”，可信 DNS 也不例外，并在所有排序方向置底；最新一轮有成功查询后恢复正常评级规则。窗口内无采样仍显示“待评估”。当前评级使用可配置的近期窗口，默认 60 分钟，达到 3 次正式采样和 5 分钟有效覆盖后评分。

质量评分综合可用率（45%）、查询成功率（35%）及 P95 时延（20%）。A ≥ 95 分，B ≥ 85 分，C ≥ 70 分，D < 70 分；参考一致或正常时按上述性能评分；可疑时评 E，疑似或人工确认污染时优先评 F。

P95 时延 ≤ 50 ms 时获得全部时延分，≥ 2000 ms 时为零分，中间线性递减。样本、时间覆盖或解析依据不足显示“待评估”；悬停可查看原因和进度。详情中的性能指标与图表保留所选历史区间；退避期间未发生的探测不会伪造成成功。

每次实际探测的原始记录保留滚动 30 天，超期自动删除。图表按时间聚合。总览的“导出当前结果”保留当前统计区间、筛选与排序；下方入口导出所选区间内全部服务器的原始记录。
